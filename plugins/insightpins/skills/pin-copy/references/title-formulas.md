# Headline formulas

Use these for the on-image headline (3-8 words) and adapt them, with the keyword added, for the pin
title (up to 100 characters). Fill brackets with real details from the page.

## Angles

Each angle is a different reason to click. For variations, use a different angle per pin.

| Angle | Formula | Example |
| - | - | - |
| Number / list | [N] [Adjective] [Things] [for Outcome] | 17 Cozy Fall Dinners |
| Outcome / benefit | [Get Result] [Without Pain] | Clear Skin Without Expensive Products |
| How-to | How to [Do Thing] [Qualifier] | How to Paint Kitchen Cabinets Like a Pro |
| Speed / ease | [Thing] in [Time] / Easy [Thing] | 20-Minute Weeknight Pasta |
| Money | [Thing] on a Budget / Under [$X] | Small Bathroom Makeover Under $200 |
| Audience | [Thing] for [Who / Situation] | Workouts for Busy Moms |
| Mistake / warning | [N] [Thing] Mistakes to Avoid | 7 Houseplant Mistakes to Avoid |
| Before / after, transformation | [From] to [To] | From Cluttered to Calm in a Weekend |
| Best / ultimate | The Best [Thing] for [Use] | The Best Carry-On Packing List |
| Question | [Problem]? Try This | Dry Houseplants? Try This |
| Seasonal / timely | [Season/Event] [Thing] | Easy Christmas Cookie Ideas |
| Curiosity with substance | The [Thing] [Group] Swear By | The Cleaning Trick Pros Swear By |

## Power words (use sparingly, only when true)

Easy, quick, simple, best, ultimate, cozy, budget, cheap, healthy, no-bake, beginner, step-by-step,
DIY, printable, free, aesthetic, small-space, foolproof, essential.

## Pin title patterns (with keyword first)

- `[Primary keyword]: [benefit or number]` - "Small Bathroom Ideas: 25 Ways to Make It Feel Bigger"
- `[N] [Primary keyword] [qualifier]` - "17 Easy Chicken Dinner Recipes for Busy Weeknights"
- `[Primary keyword] for [audience]` - "Meal Prep for Beginners: A Simple 5-Day Plan"

## Avoid

- Vague or clever-only headlines ("Life Changing!", "You Need This").
- Questions with obvious "no" answers.
- Exaggeration the page doesn't support ("Lose 20 lbs in a Week").
- Health, money or medical promises without the page backing them; Pinterest limits misleading claims.
- Headlines longer than about 8 words on the image; move detail to the subtitle or description.
